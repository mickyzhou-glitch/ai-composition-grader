# 范文结构校验与自动返修（2026-11-05，**未上线**）

- 分支：`fix/structure-audit-rework`（仅本地提交，未 push、未部署、无数据库迁移）
- 起因：章皓轩「这件事打动了我」范文没按五段结构写；结构复核由模型自评一句「符合」即放行，且结果不落库。

## 改动

1. 解析：`structureRequirements` 支持「第一段：/第1段：/开头段/结尾段」（标题与要求可分行或同一行连写）和与段数相同的「1. 2. 3.」编号；每段拆成可逐个核对的要素，并识别「约N字 / N-M字 / N字左右」。
2. 复核（`src/ai/structure-audit.ts`）：模型逐段逐要素给 `met/unmet/superseded` + 范文原句证据；最终 pass/fail 由程序判定——任一要素 unmet、met 却在该段找不到证据、或汉字数偏离「约N字」超过 30%，该段即不合格。
3. 自动返修：不合格段的逐条失败原因作为硬约束喂回改写，只改受影响段；最多返修 2 次，每次返修后重新复核；仍不合格则拒绝保存，错误码带段号（如 `rewritten_essay_structure_p1_p4`）。
4. 落库：每轮复核（逐段要素、证据、字数、失败原因）写入 `report.structureAudit`（`version/passed/repairAttempts/rounds`）；模型自报的同名字段一律丢弃。
5. **第一段口径（家奇订正）**：欲扬先抑结构（后续段落提到「抑」）下，第一段只写名人名言、简单解释名言、点出人物，最多一句过渡；配置里「埋下抑的伏笔」按「点到即可、最多一句」理解；第一段两句以上或约三分之一以上篇幅写人物缺点、误解、他人排斥等「抑」内容 → 判 fail 并返修，「抑」放在第二段。生成、复核、返修三处提示词都写明。
6. 老师本轮意见写了硬性字数的段，以老师为准，不再套配置约数；老师更正人物事实、OCR 不准编等既有规则不变。
7. 去掉了上一版草稿里输出复核失败详情的 `console.warn`（违反适配器不打作文日志的安全约束）。
