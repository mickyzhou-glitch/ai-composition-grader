# 班级分类与文档上传

上传时填写可选班级，最多 50 字；可复用本账号历史班级。每条作文保存班级，空值显示“未分类”。历史记录和批量审核支持班级与姓名组合筛选，跨账号隔离。

支持单份 Word（.docx）或 PDF，单文件不超过 20MB，每份对应一篇作文。浏览器按需加载解析器，转换为最多四页图片后供老师预览、排序、裁剪，再沿用现有 OCR、批改、审核及导出。PDF 保留页面，Word 按正文和内嵌图片重新分页；界面说明重排并要求检查预览。原始文档无需上传或保存。

转换失败、空文档、加密 PDF 或超过四页时明确提示，保留先前选择。转换期间锁定上传与下一步，页面离开时释放预览资源。班级不发送至 AI。

验收包括班级持久化和隔离、组合筛选、文档边界校验、Word/PDF 实际浏览器转换，以及原有测试、类型检查和静态构建。
