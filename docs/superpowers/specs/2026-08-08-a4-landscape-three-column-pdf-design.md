# A4 横向三栏 PDF 设计

## 目标

将作文批改 PDF 恢复为简洁的横向三栏学习页。每张学生作文图片对应 1 张标准 A4 横向页面，不再输出独立的「优点」和「需要修改」摘要页。

## 页面结构

每页固定为以下三栏：

1. 左栏：当前页对应段落的修改建议。
2. 中栏：学生上传的作文原图。
3. 右栏：当前页对应的范文段落。

页面使用 `A4 landscape`，三栏保持现有的建议、原图、范文顺序。范文仍按现有规则分配到各作文页，不新增标题卡片、边框、批注图层或说明文字。

## 视觉规则

- 范文栏使用红色、楷体，包括「改后范文」、段落标题和范文正文。
- 修改建议及其他可见文字使用蓝色、黑体。
- 中间图片使用 `variant=original` 返回的原图，不叠加红圈、下划线、批注或其他图层。
- 原图使用等比例完整显示，不裁切、不拉伸。

## 数据与错误处理

- 保留现有打印页的数据读取、图片加载等待和 PDF 缓存机制。
- 报告或图片缺失时继续使用现有错误处理。
- 本次不修改 AI 报告结构、作文图片存储或下载接口。

## 测试与验收

- 组件测试确认只输出与作文图片数量一致的三栏反馈页，不再输出摘要页。
- 组件测试确认左侧仅显示修改建议，中间加载原图，右侧仅显示范文。
- 样式回归检查确认页面为标准 A4 横向，范文为红色楷体，其他文字为蓝色黑体，原图完整显示。
- 运行相关 Vitest 测试、ESLint 和 Next.js 构建。
