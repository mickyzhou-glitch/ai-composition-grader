# 2026-10-21 老师补充观点输入修复

- 问题：新版逐段报告生成后，“老师补充观点”输入框错误地被禁用，教师无法补充重新分析要求。
- 根因：输入框沿用仅允许旧版报告编辑的判断条件；重新分析 API 和任务、模型链路已支持老师观点。
- 修复：移除报告类型限制，仅在操作提交或分析任务进行时禁用输入框。
- 回归：覆盖新版报告输入观点后通过“重新分析”（full）和“重新生成整篇批改”（content_only）提交，以及排队后禁用输入。新增两个组件用例先复现失败，修复后通过。
- 验证：4 个相关测试文件、168 项测试通过；修改文件 ESLint、差异格式检查和生产构建通过。本地与正式站点各 2 项浏览器回归通过。
- 正式浏览器验证加载真实线上页面资源，账号和业务 API 使用模拟数据，确认输入可用、观点和模式随请求提交；未创建真实作文、未调用真实 AI。
