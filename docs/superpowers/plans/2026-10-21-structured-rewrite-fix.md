# 首次批改与退回修改的结构要求修复

## 线上证据与根因
- 指定记录已保存完整五段结构配置和两次教师修改要求；原文识别为三段。
- 内容模型只输出一对一原文段落修改稿，锁定原文段数；教师意见被错误弱化成非指令数据。

## 实现与验收
1. 保留原文点评映射，新增独立完整范文 rewrittenEssay，供首次、内容重生、退回修改共同使用。
2. 配置中的结构、写作技巧、年级、字数分配与教师后续意见作为生成要求；人物事实与输出格式边界仍有效。
3. 校验完整范文段数，错误时修复一次，再失败返回明确错误；兼容历史报告。
4. 页面编辑、保存与 PDF/Word 导出都包含完整范文；覆盖原文三段、目标五段的回归。
5. 测试、生产构建、发布和线上验证。实际模型验证与模拟浏览器验证分别记录。

## 验证与发布
- 全量单元测试：95 个文件、1096 项通过；生产构建和全项目 TypeScript 检查通过。相关文件 ESLint 无错误（测试桩存在两项未使用参数警告）。
- 本地浏览器回归：五段范文展示、编辑、保存，以及教师意见随 full / content_only 提交，共 3 项通过。
- 发布后针对正式站点静态资源运行相同 3 项浏览器回归，全部通过。这组回归模拟接口响应，不作为真实模型生成证明。
- Cloudflare 已发布版本：`24ab0248-cb8a-494b-9322-2ae238f3e845`。
- 正式地址：https://ai-composition-grader.mickyzhou7.workers.dev
- 真实模型测试使用独立的合成作文，记录名“功能测试-五段结构”，原文三段、要求五段；未覆盖或重新生成用户原作文。
- 首次真实测试触发 `schema_report_unrecognized_keys`。已明确禁止输出未定义字段、去掉范文字数提示中旧字段措辞，并在一次修复提示中列明要删除的额外键名；新增对应回归测试。
- 后续真实测试确认外层重复 `parentFeedbacks`。AI 接收边界仅去除根对象/报告对象的额外字段，完整范文、逐段点评、诊断和批注的必填与语义验证继续执行。
- 实际模型还曾把目标范文段数用于原文点评，触发 `paragraph_review_coverage`；已加入依据本次原文编号、原文段数与目标段数动态构建的完整 JSON 模板，并在首次与修复提示中明确分别约束两个数组。
- 真实初次生成成功：识别原文 3 段、原文点评 3 项，独立范文 5 段。逐段核对依次具备引入、误解铺垫、清晨劳动事件、邻居揭示原因和结尾感悟。页面显示“共 5 段”。
- 继续通过正式站点“批量作文审核 → 不合适 → 提交后台修改并继续”提交合成测试的细化要求：仍为五段、前两段合计不超过 120 字、第三段不少于 180 字，指定末句以验证后续意见确实作用于正文。
- 首次退回修改已生成五段并扩写第三段，但前两段仍超过新上限，指定末句前带了额外前缀。已明确取消初始配置“唯一标准”的冲突措辞，将最新教师意见放在初始规则之后，并要求实际计数及逐字独立句核对；添加回归后再次发布并进行真实复测。
- 第二次真实复测指定末句已独立原样出现，但第三段仍少于 180 字。新增明确自然语言硬限制的实际汉字数校验：支持“前两段合计不超过…”、“第一、二段合计不超过…”、“第三段不少于…”等无歧义表达；不把约数、事实数字或退回原因解释为硬限制。失败时将实测值反馈到现有一次修复流程，再失败不保存成功结果。
- 第三次真实测试修复后前两段实测 122 汉字，硬校验正确拦截，保留之前报告。随后为模型明确不含标点的计数口径，并从已解析限制生成留有余量的目标提示，降低边界计数误差；通过“老师补充观点 → 重新生成整篇批改”再次检验相同要求。
- 整份报告修复仍可能未扩写到下限，因此字数错误改为仅重写完整范文的专用修复请求，传入每段实测汉字数、完整教师要求和原文事实；保留初次生成的点评、批注并在合并后重新验证全部结果。最多仍是原有的一次修复，不增加调用上限。专用修复也明确将原文和旧范文视为数据。
- 全项目 TypeScript 检查另外发现此前新增界面测试误用了 Playwright 的 exact 选项，已移除；对应界面和适配器测试、全项目类型检查通过。
- 最终真实模型验收通过：五段范文、前两段合计 94 个汉字（上限 120），第三段 186 个汉字（下限 180），凌晨四点扫街和坚持十几年事实保留；末句独立且逐字为“那个干净的街角，成了我每天认真说早安的地方。”，页面状态恢复为“待复核”。完整范文共 431 字（含标点）。
- 线上截图：`output/structured-rewrite-live.png`；合成数据验收结果：`tmp/structured-rewrite/final-result.json`。此验证不代表每一条自然语言要求都可机械判定；明确段数和支持表达的硬字数限制会校验，其他写作要求由教师复核。
- 段数和字数不合格现在分别提示实际原因，避免统称“格式异常”。旧报告不自动改写；用户刷新后点击“重新生成整篇批改”应用原有配置及后续要求。
