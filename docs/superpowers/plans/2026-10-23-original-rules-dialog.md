# 原话审批与退回弹窗修复

目标：待审批和通过后的长期规则保留老师原话；退回弹窗可追加同题已通过规则，两个输入框在桌面及窄屏均可操作。只修改本地代码，不部署、不运行线上回填。

实现边界：复用候选表的 `sources`，不迁移数据库。旧候选按来源原话展示，通过时每条不同原话写入一条长期规则。新候选只合并完全相同文本，移除 AI 改写调用。第二框保持单篇作用域。规则选项采用追加按钮，不删除或截断手写内容。
